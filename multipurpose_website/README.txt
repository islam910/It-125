MINITOOLS — МНОГОСТРАНИЧНЫЙ САЙТ

В проекте 10 страниц:
1. index.html — главная с каталогом функций
2. calculator.html — калькулятор
3. tasks.html — список задач с сохранением в браузере
4. notes.html — заметки с сохранением в браузере
5. timer.html — таймер обратного отсчёта
6. converter.html — конвертер длины, массы и температуры
7. quotes.html — случайные цитаты
8. color.html — генератор цветов и HEX-кода
9. password.html — генератор паролей
10. contacts.html — демонстрационная форма обратной связи

Файлы:
- HTML-файлы — структура страниц
- style.css — общий дизайн и адаптивная вёрстка
- script.js — интерактивные функции
- README.txt — эта инструкция

Запуск:
1. Распакуйте архив.
2. Откройте папку в Visual Studio Code.
3. Откройте index.html в браузере (можно использовать Live Server).
4. Навигация в шапке связывает все страницы.

Заметки и задачи хранятся локально в браузере. Форма контактов демонстрационная.
